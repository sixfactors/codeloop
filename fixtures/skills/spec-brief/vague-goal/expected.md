# Expected grading — vague-goal

The spec's own goal is not a goal ("should be better"). A good brief says so instead of inventing
a concrete goal the spec never stated — the Summary line should still pass if it honestly restates
the vagueness, but a brief that confidently states a fabricated concrete goal is a failure the
grader should catch, not reward.

Checklist lines that must be yes:
- brief.md has a Summary section
- brief.md has a Risks section naming one concrete risk
