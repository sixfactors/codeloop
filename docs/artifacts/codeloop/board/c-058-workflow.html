Approve a gate

A card parked at a gate is cleared by the role the gate names (owner or reviewer), then advanced once in the same call.

sequenceDiagram
  participant Approver as Owner or Reviewer
  participant API as Board API
  participant Engine as Engine
  participant Card as Card
  Approver->>API: approve card id, note
  API->>Engine: approveCard id, role, note
  Engine->>Card: read gate and awaiting role
  alt role matches gate awaiting
    Engine->>Card: clear gate, append approve event
    Engine-->>API: updated card
    API->>Engine: advanceCard id
    Engine->>Card: run stage done check
    Engine-->>API: AdvanceResult outcome
    API-->>Approver: 200 ok, card plus outcome
  else role does not match gate awaiting
    Engine-->>API: RefusalError
    API-->>Approver: 400, gate needs a different role
  end

Entity state

State diagram for the card this workflow drives.

stateDiagram-v2
  [*] --> InStage
  InStage --> ParkedAtGate : done check passes into a gated stage
  ParkedAtGate --> InStage : approve (role matches) -> advance
  ParkedAtGate --> InStage : reject -> returned to the prior stage with a note
  InStage --> Stuck : done check fails repeatedly
  Stuck --> InStage : approve clears "stuck", resets retries
  InStage --> Done : last stage's done check passes
  Done --> [*]
