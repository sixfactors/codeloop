Design contract

Spacing/radius tokens drawn with: space-1..6 (4/8/12/16/24/32), radius-card, radius-pill, radius-sheet, see templates/artifacts/base.css. No per-screen padding outside that scale.

Presentation per surface: the board is a full page (push navigation, not a sheet). The card drawer is a sheet (side-presented), not a dialog, it needs the full scroll height for events and keeps the board visible behind it.

Problem surfaces: board load failure uses an inline callout inside the main content area (the table region, not a toast, it blocks the one thing the screen is for). Card drawer's approve conflict uses the same inline callout inside the sheet, scoped to the action that failed, not the whole drawer.
