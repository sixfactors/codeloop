On 2026-10-16, 25 of 57 open stories were stuck with no work tried, and the story page showed only raw check output (gotchas/stuck-without-any-work.md). This feature covers the fixes that let the loop run without the owner clearing it by hand: plain-words stuck explanations, failures counted only when work was tried, the orchestrator's review pass, and a card that always finds its own spec and shows real working time.
