Codeloop Cloud is the hosted version of codeloop on Protobox. It covers everything that needs a server: a board a team shares across machines with sign-in and roles, a public read-only copy of a real board and wiki so visitors can see the loop working before they install it, and the database-backed storage that makes both possible (owner decisions 2026-10-17: each story's state and history live in its own folder in git; Codeloop Cloud is a context and coordination hub for agents people run on their own machines, and never runs agents or touches code). The open-source CLI keeps working alone; Cloud adds sharing.

Supersedes hosted-board-the-team-shares, whose features moved here.
