# Mock rubric

What the mock stage must satisfy before it counts as done. The mock stage writes HTML, so its attest lines go under `## Rubric` in `{spec}/rubric-mock.md`.

M1 | `screens:` in spec.md names every screen, or says none with a reason | check
M2 | One frame per screen per state: empty, loading, normal, error, needs-you where it applies | check
M3 | Built from the project's design system and the registry's blocks, nothing hand-rolled | review
M4 | Every acceptance line can be pointed at in a frame | attest
M5 | Copy in the frames is final, not lorem | review
M6 | A reviewer can say what the user does next on each frame without asking | review
