# Spec rubric

What the spec stage must satisfy before it counts as done. Attest lines go under `## Rubric` at the end of tasks.md.

S1 | Title, story, persona, size, metric, done_when pass the story standard | check
S2 | One to five acceptance lines, Given, when, then, each noticeable by a user | check
S3 | Every interview answer appears in a field, named | attest
S4 | Every acceptance line has at least one task; every task has one layer tag and names its line | check
S5 | Tasks run service, API, SDK, UI, in that order | check
S6 | `not_building:` lists what the interview put out of scope | attest
S7 | An L is split before the gate | check
